Level 3 includes institutional publications from ECB and NIST and a secondary compilation from Elvinger Hoss Prussen. Source PDFs are not included in the repository; review publisher reuse terms before downloading or redistributing them.

**Inventory status:** links below are preserved from the submitted repository. This revision does not certify that every URL is reachable, that the files were downloaded, or that a current consolidated version is loaded into the RAG workspace. ## Source provenance and version control

For each ingested PDF, record the title, publisher, CELEX/ELI or publication identifier, source URL, publication/version date, retrieval date, local filename, and SHA-256 digest. Record whether it is an original act, consolidated text, framework, or secondary commentary. Log which version was ingested, the ingestion date, and the resulting chunk count.

HTTPS protects transport when correctly implemented; it does not establish that a downloaded document is current, that its interpretation is correct, or that the workspace contains the intended file. A locally calculated digest supports reproducibility, not publisher authentication by itself.

Check identifiers and effective/application dates against the official record. DORA's application date is distinct from entry into force. Each delegated or implementing instrument has its own dates; do not apply one date to every source.

No download log, digest manifest, or signed review record was supplied with this repository. Historical assertions that all downloads, links, and cross-references were verified are therefore replaced by this documented verification procedure.

| Field | Value to record per source |
| --- | --- |
| Source ID and legal/publication identifier | Pending source-by-source inventory |
| Exact edition and amendment status | Pending verification |
| Download URL and retrieval date | Record at download time |
| Local filename and SHA-256 | Record from actual local artifact |
| Ingestion date and chunk count | Record from the workspace |
| Reviewer, review date, and limitations | Pending human review |
